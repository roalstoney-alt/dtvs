# Contributing

Contributions are welcome through narrowly scoped issues and RFCs.

For every proposed change, state:

1. the failure or cost condition being addressed;
2. the frozen input and expected output;
3. the evidence required to accept the change;
4. whether the change modifies the core standard, a domain profile, or only the reference implementation;
5. any new security, copyright, energy, or verification risk.

Do not upload source films, commercial restoration masters, copyrighted subtitles, private customer data, credentials, or node identifiers.
