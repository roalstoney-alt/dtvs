# Security policy

The Pilot executes local media only. It does not download tasks or run untrusted containers.

Report vulnerabilities privately to the repository maintainer. Do not publish credentials, local paths containing personal names, device serial numbers, public IP addresses, or samples that expose third-party data.

Before an external-node Pilot, DTVS must add signed Task Bundles, sandboxing, least-privilege filesystem mounts, egress controls, artifact scanning, and adversarial-node tests.
